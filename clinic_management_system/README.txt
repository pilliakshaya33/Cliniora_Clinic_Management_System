CLINIORA CLINIC MANAGEMENT SYSTEM

Install: pip install -r requirements.txt
Run: python app.py
Open: http://127.0.0.1:5000

DEMO LOGINS
Admin: admin / admin123
Doctor: doctor / doctor123
Receptionist: reception / reception123

ROLE ACCESS
Admin: Overview, Patients, Doctors, Appointments. Can register patients, add doctors, and manage appointments.
Receptionist: Overview, Patients, Doctors, Appointments. Can register patients and manage appointments; doctor directory is view-only.
Doctor: Overview, Patients, Doctors, Appointments, Consultations. Can view patient, doctor and appointment information and manage consultation records.
Consultations are restricted to Doctor. Existing modules and visual design are retained.
